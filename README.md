Chapter 3: Setup NodeJS/Express/Typescript

Cài typescript để code express và nodejs cần 3 thư viện chính
- typescript: Biên dịch code ts thành js để production có thể triển khai
- @type/node: Giúp code node js được gợi ý
- @type/express: Giúp code express được gợi ý
Hai thư viên hỗ trợ khác là
- nodemon: Khi có sự thay đổi ở folder src nó sẽ tự start lại server
- ts-node: Chạy luôn code typescript thay vì phải biên dịch
